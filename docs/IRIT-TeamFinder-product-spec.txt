# Продуктовая спецификация: IRIT TeamFinder

**1. Название продукта:** IRIT TeamFinder.

**2. Описание:** Веб-сервис для поиска участников команды на хакатоны среди студентов ИРИТ-РТФ УрФУ.

**3. Целевая аудитория:** Студенты ИРИТ-РТФ УрФУ, заинтересованные в участии в хакатонах и командных IT-проектах.

**4. Проблема:** Студентам сложно самостоятельно найти подходящих тиммейтов с нужными навыками, интересами и свободным временем.

**5. Решение:** Создание единой платформы, которая автоматически подбирает совместимых участников для формирования команд.

**6. Основной функционал:**
- Регистрация и заполнение анкеты (имя, роль, навыки, Telegram).
- Выбор интересующих направлений и технологий.
- Автоматический подбор участников по совместимости.
- Уведомления о найденных тиммейтах через Telegram.
- Возможность связаться с потенциальными участниками.

**7. Уникальность продукта:** Быстрый поиск команды внутри студенческого сообщества ИРИТ-РТФ с учётом технических навыков и предпочтений участников.

**8. Ключевые метрики успеха (KPI):**
- Количество зарегистрированных студентов.
- Количество заполненных анкет.
- Количество успешных совпадений (Match).
- Процент пользователей, сформировавших команду.
- Среднее время поиска команды.

**9. MVP:** Первая версия включает анкету пользователя, алгоритм подбора тиммейтов и Telegram-уведомления.

**10. Цель MVP:** Проверить, помогает ли сервис студентам быстрее находить подходящих участников для хакатонов.
